# In-game icons: credits

Echo Atlas is an unofficial, non-commercial fan project used for testing, not affiliated with or endorsed by Kuro
Games. Every icon in this folder is a texture from the game Wuthering Waves, © Kuro Games. They are local copies,
shown only in this playground with this credit, and will be removed on request.

They were fetched on 2026-10-24 from the public game-data API of [Encore](https://encore.moe), a fan-run Wuthering
Waves database that serves the game's own UI textures (plain requests, an honest user agent, no access controls
bypassed). The Wuthering Waves Wiki (Fandom) was tried first; it forbids embedding and scripted downloads, so none of its
files are used.
